# Commonwealth Games Medalists – Power BI Dashboard

## Project Overview

This project presents an interactive **Microsoft Power BI dashboard** for analyzing Commonwealth Games medalists and medal performance across countries, athletes, events, and historical years.

The dashboard transforms medal data into interactive visualizations that allow users to explore country performance, athlete achievements, event-level statistics, and historical medal trends.

The analysis covers Commonwealth Games medal data from **1930 onwards**, depending on the availability of records in the dataset.

---

## Project Objectives

- Analyze medal performance across Commonwealth Games.
- Compare medal performance between countries.
- Identify top-performing athletes.
- Analyze medals across different events.
- Examine historical medal trends.
- Provide interactive filtering and exploration.
- Present the results through an intuitive Power BI dashboard.

## Dashboard Pages

### 1. Overview

The Overview page provides a high-level summary of Commonwealth Games medal performance.

**Includes:**

- Country comparisons

- Overall medal statistics

### 2. Country Performance

The Country Performance page focuses on comparing medal performance between countries.

**Includes:**
- Country-level filtering

### 3. Athletes and Events

The Athletes and Events page provides detailed analysis of athletes and sporting events.

**Includes:**

The Historical Trends page examines changes in Commonwealth Games medal performance over time.

- Area charts
